# WordRoom 단어 링크 판정 개선 제안서 — `와/과` 경계

**기준일 2026년 11월 26일** · 대상: [링크 추출](../Assets/WordRoom/Scripts/Shelf/ShelfLinkText.cs) · [방 그래프](../Assets/WordRoom/Scripts/Shelf/ShelfLinkGraph.cs) · [링크 판정 테스트](../Assets/WordRoom/Tests/EditMode/ShelfLinkTextTests.cs) · 사전 패키지 `6773adfc…`

[단어 링크 판정 설계](WordRoom_단어링크_판정설계.md)가 정리한 `말과` 문제를 현재 코드와 사전 원문으로 다시 확인하고, 개선 방식을 비교해 추천안을 제시한다. 확인해 보니 문제는 `말과` 한 단어에 그치지 않는다. `명사 + 와/과`와 글자가 같은 표제어가 패키지에 73개 있고, 이 때문에 화면에 잘못 표시되는 링크가 약 290건이다. 추천안은 어절마다 분리 후보를 만들고 앞뒤 문맥 단서로 하나를 고르는 방식이다. 이 방식은 와/과 경계 오링크 283건을 고치고 기존 검수 예외 23건을 대신한다. 새로 생기는 오링크는 1건이고, 사라지는 올바른 링크는 7건이다. 비교 표현 목록만 늘리는 방식은 20건을 고친다.

> **수치의 출처.** 현재 C# 규칙(어미 목록과 예외 표 포함)을 Python으로 그대로 옮겨 패키지의 뜻풀이 48,318개 전체에 적용한 값이다. 도구는 [Tools/LinkJudgment](../Tools/LinkJudgment/link_compare.py)에 있고, `python link_compare.py diff context` 등으로 다시 계산할 수 있다. 링크 설정은 씬과 테스트에서 쓰는 값(빈도 상위 15,000개, 2글자 이상)이고, 방 유효성은 목표 `지구` 기준이다. 옮긴 규칙은 테스트의 실데이터 사례(`영화용`, `결과의 비율`, `모자라는`, `말과의 포유류`, `조사`·`토`)를 C# 테스트의 기대값과 같게 재현했다. C#으로 구현한 뒤에는 같은 비교를 C#으로 다시 실행해 수치를 확정한다(8장).

> **1차 적용 기준.** 5장의 프로이트는 `[신경과]`를 유지한다. 6장의 손실·오판 수치는 Python 실험 결과다. 실제 적용 범위와 검증 결과는 [단어 링크 판정 설계](WordRoom_단어링크_판정설계.md)에 기록한다.

## 2. 현재 판정과 실제 영향

### 2.1 잘못된 표제어가 정해지는 단계

패키지에는 `X + 와/과`와 글자가 같은 표제어 `X과`·`X와`가 73개 있다(X도 등재어이고 받침과 조사가 맞는 경우). `말과`·`콩과`·`정신과`처럼 `-과(科)`가 붙은 합성어와 `등과(登科)`·`산과(産科)`·`성과(成果)`·`일과(日課)`·`도와(陶瓦)` 같은 한자어가 여기에 속한다. 문장에서는 이 어절이 대부분 `X + 조사`다(`등과 날개`, `산과 들`, `성과 이름`). 오판은 다음 단계에서 생긴다.

| 어절 형태 | 현재 판정 | 결과 |
|---|---|---|
| `X과` + 다음 어절 | 비교 구문 규칙은 다음 어절이 여섯 형태와 정확히 같을 때만 작동한다. 그 밖에는 **어절 전체 등재** 단계가 먼저 `X과`를 고른다. | 오판이 이 단계에서 정해진다. 이후 링크 조건과 중복 제거는 이 결정을 다시 판정하지 않는다. |
| `X과의`·`X과는`·`X과도` | `X + 과의`와 `X과 + 의`가 모두 등재어라 일반 글자로 둔다. | 오링크는 생기지 않는다. 분류 링크(`콩과의 한해살이풀`)도 같은 이유로 사라지므로, 사례마다 뜻풀이별·어절별 예외를 추가해 보존하고 있다. |
| 받침이 맞지 않는 분리 | 비교 구문 규칙만 받침을 본다. 일반 분리 단계는 받침을 보지 않는다. | 접미사 자리를 조사로 잘라 어근에 링크한다. `국화과의 → [국화]`, `법률가 → [법률]`, `항공로 → [항공]` 등 100건이다. |

### 2.2 추출 단계 오판과 화면 오링크

추천안을 적용하면 와/과 판정이 바뀌는 어절이 358개다. 이 중 291개는 화면 링크가 바뀐다. 57개는 추출 결과만 바뀌어 지금 화면에는 영향이 없고, 10개는 지금도 링크가 없다.

| 구분 | 건수 | 화면 영향 | 실제 예 |
|---|---|---|---|
| 화면에 표시되는 오링크 | 283 | 클릭하면 엉뚱한 방으로 이동하고, 방 그래프의 거리 계산에도 들어간다. | `기린` 말과 같으며 → `[말과]`, `갈매기` 등과 날개는 → `[등과]`, `참모` 윗사람을 도와 → `[도와]`, `산정` 산과 들 → `[산과]`, `동종` 성과 본이 같은 → `[성과]`, `수행` 정신과 육체를 → `[정신과]` |
| 화면에 표시되는 올바른 링크 | 8 | 추천안에서 잃거나 바뀌는 링크(6장) | `숙제` 방과 후에 → `[방과]`, `프로이트` 신경과 의사 → `[신경과]` |
| 추출만 오판: 방이 없는 뜻풀이 | 35 | 없다. 한 글자 표제어 등이라 방이 만들어지지 않는다. | `문`·`월` 말과 글로, `연` 원인을 도와, `염` 산과 염기 |
| 추출만 오판: 도착할 방에 출구가 없음 | 15 | 지금은 없다. 링크 설정이 바뀌어 그 방이 유효해지면 나타난다. | `바둑` 흰 돌과 검은 돌 → `돌과`, `산술` 수와 양 → `수와` |
| 추출만 오판: 같은 뜻풀이의 중복 | 7 | 없다. 앞쪽 링크만 표시된다. | `당나귀` 말과 비슷한데, `복식` 일 등과 이 등 |
| 현재도 링크 없음 | 10 | 없다. 판정 근거만 달라진다. | `조사`·`토` 다른 말과의 문법적 관계, `열역학` 일과의 관계 |

화면 오링크가 많은 표제어는 `[등과]` 37건, `[도와]` 29건, `[말과]` 20건, `[일과]` 19건, `[산과]` 15건, `[성과]` 14건, `[적과]` 11건, `[열과]` 9건 순이다. 현재 화면의 `[말과]`는 21건이고, 이 중 `당나귀`의 `[말과]의 포유류`만 올바르다. 나머지 20건은 비교 문장 3건(`기린`, `인수`, `유니콘`), 동반·관계 문장 3건(`알라`의 다른 말과 함께, `반점`·`쉼표`의 다음 말과 직접적인 관계), 나열 문장 14건(`연극`, `연희` 2건, `문장`, `언행`, `대인`, `공안`, `장차` 등)이다.

### 2.3 같은 구조이지만 이번 범위에서 제외한 문제

- **다른 조사 앞에서 어절 전체가 등재된 경우.** `말과 [글로]`, `당나귀`의 `[귀가] 길다`, `조사`의 `그 [말의] 뜻`, `기린`의 `상상 [속의] 짐승`, `숙제`의 `방과 [후에]`가 여기에 속한다. 추천안의 단서를 모든 조사로 넓혀 시험해 보니 화면 링크 약 5,500건(와/과 변경 포함)이 바뀌었고, `[서로]`(476건)처럼 올바른 링크도 함께 사라졌다. 따라서 별도 설계와 검수가 필요하다.
- **용언 활용형이 명사 표제어와 같은 경우.** `몸은 [작고]`, `[보여] 주는`, `[달리]`가 여기에 속한다. 패키지에는 명사만 있어 사전만으로는 용언을 알아볼 수 없다. `도와`는 와/과 충돌이라 이번 범위에서 함께 해결된다.

## 3. 개선안 비교

- **방식 A — 비교 규칙 확장.** `ComparisonWords`를 어간 앞부분 일치(`같-`, `다르-`·`다른`·`달리`·`달라`, `비슷-`, `닮-`, `유사-`, `동일-`, `흡사-`)로 바꾼다. 나머지 판정 순서는 그대로다.
- **방식 B — 분리 후보와 문맥 선택(추천).** 어절마다 받침 규칙에 맞는 후보(어절 전체, 등재어 + 허용 어미)를 만든다. 후보가 `X + 와/과 계열 조사`와 `X과·X와 표제어`로 갈리면 앞뒤 문맥 단서로 하나를 고른다. 단서가 없으면 일반 글자로 둔다.

| 항목 | A 비교 규칙 확장 | B 분리 후보 + 문맥 선택 |
|---|---|---|
| 고치는 화면 오링크 | 20건(비교 문장만) | 와/과 경계 283건, 받침이 맞지 않는 접미사 분리 100건(7장 2·3단계) |
| 새로 생기는 오링크 | 0 | 1건(`신경과 의사 → [신경]과`) |
| 사라지는 올바른 링크 | 0 | 7건(6장) |
| 남는 와/과 오링크 | 약 270건(`말과 글로`, `강과 시내`, `등과 함께` 등) | 약 10건(6장) |
| 기존 검수 예외 49건 | 그대로 둔다. 새 사례가 나오면 예외를 추가해야 한다. | 23건을 일반 규칙으로 대신한다. |
| 사용하는 데이터 | 다음 어절 | 다음 두 어절, 앞 어절, 출발 뜻풀이의 분야, 다음 명사의 분야, 패키지 뜻풀이 전체의 용례 수. 모두 기존 패키지에 있는 데이터다. |
| 변경 범위 | `ShelfLinkText`의 목록 한 곳 | `ShelfLinkText` 판정부, `ShelfLinkGraph`의 문맥 제공, 테스트 |
| 계산 비용 | 변화 없음 | 그래프를 만들 때 충돌 표제어 73개와 그 앞부분 명사의 용례 수를 한 번 센다. |

**B를 추천한다.** 와/과 오링크의 93%는 비교 구문 밖에 있어 A로는 고칠 수 없다. B는 기존 사전 패키지와 C#만으로 구현할 수 있다. 또 예외를 늘리지 않고 오히려 줄인다. 손실 7건과 새 오링크 1건은 모두 실제 문장으로 확인한 목록이므로 검수할 수 있다.

## 4. 추천안의 판정 순서

**0. 기존 검수 예외.** 뜻풀이별 예외, 동사 활용형, 수량 뒤 단위, 어절별 예외 순으로 본다. 사람이 문장을 읽고 확정한 결과이므로 맨 앞에 둔다. 일반 규칙이 같은 결과를 내는 23건은 테스트로 확인한 뒤 삭제한다(7장 4단계).

**1. 후보 생성.** 어절 전체가 등재어이면 전체 후보가 된다. 허용 어미 하나를 뗀 앞부분이 등재어이면 분리 후보가 된다.

**2. 받침 규칙.** 앞 음절의 받침과 맞지 않는 조사로 만든 분리 후보를 버린다.

| 조사 | 앞 음절 조건 |
|---|---|
| `과`·`과의`·`과는`·`과도` | 받침 있음 |
| `와`·`와의`·`와는`·`와도` | 받침 없음 |
| `은` / `는`, `이` / `가`, `을` / `를` | 받침 있음 / 받침 없음 |
| `으로…` / `로…` | ㄹ 아닌 받침 / 받침 없음 또는 ㄹ |
| `라는`·`라고`… (서술격 `이`가 줄어든 형태) | 받침 없음 |

서술격 `이다`·`이나`·`이란` 계열은 받침 없는 말 뒤에도 쓰이므로(`정도이나`) 거르지 않는다. 끝 글자가 한글이 아니면 거르지 않는다. 이 규칙으로 `사과 같은`은 `사 + 과`가 될 수 없어 `[사과]`로 정해진다. `교과의`·`효과의`·`신라는`·`경로의` 같은 어절은 예외 없이 분리가 하나로 정해진다.

**3. 와/과 경계 충돌 판정.** 남은 후보가 `X + 와/과 계열 조사`와 `X과·X와 표제어(+ 의·는·도)`로 갈릴 때만 적용한다. 아래 단서를 순서대로 보고 처음 맞는 단서로 정한다. 실측 열은 패키지 전체의 충돌 어절 487개에 적용한 결과다. 오판 수는 해당 문장을 모두 읽고 확인했다.

**4. 충돌이 아닌 여러 후보.** 현재 규칙을 유지한다. 전체 후보가 있으면 전체를 고르고(`비공개`, `에도`), 없으면 분리 후보가 하나일 때만 고른다. 분리 후보가 여럿이면 일반 글자로 둔다.

**5. 링크 조건과 방 필터.** 현재와 같다. 정한 표제어 하나에만 링크 조건을 적용하고, 조건을 통과하지 못하면 일반 글자로 둔다. `말과`를 `말 + 과`로 정하면 `말`은 한 글자라 일반 글자가 되고, `말과`로 되돌아가지 않는다.

### 판정 원칙

- **활용형은 어간 앞부분으로 맞춘다.** `같고`·`같으며`·`같이`는 `같-`으로, `비슷한데`·`비슷하며`는 `비슷-`으로 판정한다. 이 단서는 와/과 충돌 어절의 다음 어절에만 쓰므로 다른 어절의 판정에는 영향을 주지 않는다. 실측 75건에서 오판이 없었다.
- **명사 나열은 표지가 있으면 문법 단서로, 없으면 용례 빈도로 정한다.** 같은 명사 반복과 `아울러`·`통틀어` 관용구가 있으면 3-3·3-4로 정한다. `말과 글로`·`말과 동작으로`처럼 표지가 없는 나열은 3-8에서 `말`(5,203회)과 `말과`(0회)의 차이로 정한다. 어절 전체가 표제어인 `사과 주스`는 2단계 받침 규칙에서 충돌이 아니게 되어 `[사과]`를 유지한다. `정신과 진료`는 3-7의 분야 일치로 `[정신과]`를 유지한다.
- **문맥이 애매할 때는 일반 글자로 둔다.** 3-9까지 단서가 없으면 링크를 걸지 않는다. 잘못된 링크는 플레이어를 엉뚱한 방으로 보내고 그래프 거리도 바꾼다. 빠진 링크는 출구가 하나 줄어들 뿐이다. 현재 `X과의` 형을 처리하는 원칙과 같다.
- **`X과의` 형에서 빈도로 조사 쪽을 고르지 않는다.** `X과의 Y`를 `X와의 Y`로 읽으려면 Y가 관계를 나타내야 한다. 실제로 패키지에서 뒤에 관계 명사가 없는 `X과의`는 모두 분류명이었다(`콩과의`, `맛과의`, `열과의`, `결과의`).
- **`말과의 포유류`와 `다른 말과의 문법적 관계`는 뒤 구절로 구별한다.** 앞의 예는 3-1·3-2에 해당하는 단서가 없고, 3-7에서 `말과`(동물)와 출발 뜻풀이 `당나귀`(동물)의 분야가 같아 `[말과]의`가 된다. 분야가 없는 뜻풀이에서는 3-9에 이르러 일반 글자가 된다. 뒤의 예는 3-2에서 수식어 `문법적`을 건너뛴 다음 어절 `관계를`이 관계 명사라 `말 + 과의`가 된다. 판정 설계 문서는 앞 어절 `다른`을 단서로 제안했지만, `다른`은 분류명 앞에도 올 수 있다(`다른 콩과 식물`). 관계의 상대는 뒤에 오는 관계 명사로 확인해야 `일과의 관계`·`돌과의 관계`·`상과의 대응`에도 같은 규칙이 적용된다.
- **분야 정보의 활용 범위.** 뜻풀이의 61%(29,422개)는 분야가 비어 있거나 `없음`이다. 그래서 분야는 문법 단서보다 약한 단서로 보고 3-7에 둔다. 다음 명사의 분야는 그 명사의 모든 뜻이 전문 분야일 때만 쓴다. `대학`·`의사`·`과정`처럼 일반 뜻이 있는 명사의 분야까지 쓰면 분야 단서가 정하는 경우가 38건으로 늘지만, 그중 18건이 `일 등과 이 등`, `일과 농사` 같은 오판이었다. 지금 조건에서는 22건 중 6건이 오판이다.
- **뜻풀이 정보의 활용 범위.** 표제어의 뜻풀이로 분류명인지 알 수 있는 경우(`포유강 말목의 한 과`)는 충돌 표제어 73개 중 4개(`말과`·`맛과`·`별과`·`콩과`)뿐이다. 그래서 1차 범위에서는 쓰지 않는다. 대신 패키지의 모든 뜻풀이를 용례 말뭉치로 써서 3-8의 빈도를 얻는다. 표제어 원형의 경계 표시(`말-과`, `정신-과`)는 그 표제어가 `X + 과(科)`라는 것만 알려 줄 뿐, 문맥에서 어느 쪽으로 읽을지는 알려 주지 않는다.
- **단어 예외 대신 문법 부류를 쓴다.** 단서 목록은 비교·동반·상호 서술어, 관계 명사, 정의 관용구처럼 문법 부류의 목록이며 특정 표제어나 `SenseId`를 담지 않는다. 같은 단서가 충돌 표제어 73개에 모두 적용된다.

## 6. 알려진 손실과 남는 오류

- **새로 생기는 오링크 1건.** `프로이트`의 `신경과 의사`가 `[신경]과`로 바뀐다. `의사`에 일반 뜻이 있어 3-7이 적용되지 않고, 3-8에서 `신경`(57회)으로 정해진다.
- **사라지는 올바른 링크 7건.** `숙제`의 `방과 후에`, `본회의`의 `분과 회의`, `파스칼`과 `케임브리지`의 `공과 대학`, `이공계`의 `공과 계열`, `복수`의 `경과 중에도`, `메커니즘`의 `인과 관계`다. 모두 `X과 + 일반 명사` 형태의 복합어다. 사전에 구 단위 표제어가 없어 현재 데이터로는 나열 구문과 구별할 단서가 없다.
- **남는 오링크 약 10건.** 모두 현재도 잘못 표시되는 링크다. 분야 일치 단서가 잘못 고른 6건은 `구`(한의)의 `팔과 다리`, `연기`(불교)의 `원인인 인과 조건인`, `이장`·`상원`(역사)의 `일과`, `백제`의 `일본 등과 우호`, `사의`의 `노비의 적과 소송`이다. 문장부호 단서가 잘못 고른 경우는 `상생`의 `수는 목과,`처럼 서술어를 생략한 나열이다.
- **대응.** 손실과 오판을 줄이려고 단어별 예외를 넣지 않는다. 필요하면 `X과 + 명사` 복합어처럼 부류 단위의 데이터를 따로 검토한다.

## 7. 적용 순서

1. **기준 링크 저장.** 현재 코드로 모든 뜻풀이의 링크(SenseId, Start, Length, Target, 화면 표시 여부)를 `DataValidation/links/`(git 제외 폴더)에 저장하는 EditMode 도구를 먼저 만든다. 이후 단계마다 같은 패키지와 링크 설정으로 비교한다.
2. **와/과 받침 규칙과 충돌 판정.** 예상 변경은 와/과 경계 291건(수정 283, 6장의 손실·오판 8)과 `과` 자리의 오분리 제거 49건(`국화과의`·`장미과의`·`포도과의`·`만두과` 등)이다. 변경 목록을 모두 실제 문장으로 검수한다.
3. **나머지 조사의 받침 규칙.** `가`·`로`·`이` 등에 적용한다. 예상 변경은 51건(`법률가`, `교육가`, `항공로`, `우물가`, `기어이` 등)이며, 모두 접미사나 다른 낱말 자리를 조사로 잘못 자른 경우다. 시험 결과 유효한 방의 수(13,882개)는 바뀌지 않았다.
   - **결정 필요:** 2·3단계에서 사라지는 어근 링크(`국화과의 → [국화]`)는 "접미사는 확인된 예외에서만 자른다"는 기존 원칙에 맞지 않으므로 없애는 쪽을 추천한다. 이 링크를 살리려면 조사 분리로 남기지 말고 `-과(科)·-가(家)` 접미사 규칙으로 따로 설계한다.
4. **중복 예외 삭제.** 일반 규칙이 같은 결과를 내는 23건을 삭제한다. 뜻풀이별 예외 4건은 `126851|말과의`, `146729|말과의`, `138335|자연과의`, `244222|행정과는`이다. 어절별 예외 19건은 `결과의`, `결과도`, `경로의`, `공로의`, `교과의`, `맛과의`, `무과의`, `사과의`, `선로의`, `소아과의`, `신라는`, `열과의`, `인과의`, `콩과의`, `통로는`, `학과의`, `항로의`, `효과는`, `효과의`다. 삭제 전후의 링크 비교 결과는 0건이어야 한다. 남는 예외 26건(`영화용`, 개 + 의 10건, `전화로부터`, `미만의`, `서로의`, `회로의` 등)은 일반 규칙으로 정할 수 없는 경우다.
5. **후속 과제(별도 설계).** 다른 조사 앞에서 어절 전체가 등재된 경우(`글로`·`귀가`·`말의`·`속의`·`후에`)와 용언 활용형(`작고`·`보여`·`달리`)을 다룬다.

## 8. 완료 기준

- 5장 표의 실제 문장이 모두 '제안 후' 열과 같다. 화면의 `[말과]`는 21건에서 1건(`당나귀`의 `[말과]의 포유류`)으로 줄고, 그 1건과 `콩과의`·`맛과의`·`열과의` 분류 링크는 예외를 삭제한 뒤에도 표시된다.
- 기준 링크와 비교한 변경 목록에 6장에 적은 손실·오판 외의 회귀가 없다. 변경 건수가 프로토타입 값(2단계 291 + 49건, 3단계 51건)과 크게 다르면 원인을 확인한다.
- **본문 보존.** 모든 뜻풀이에서 `Split()` 결과를 이어 붙이면 표시용 뜻풀이와 같다. 링크 범위는 어절 시작부터 표제어 글자까지이며 `Text`와 `Target`이 같다. 기존 실데이터 검사를 유지한다.
- **화면과 그래프 일치.** 판정 문맥(분야, 용례 수)은 `ShelfLinkGraph` 안에서만 만든다. 방 그래프(`CandidateLinks`), 읽기 화면(`Doors`), 누락 로그(`ReportDropped`)는 모두 `Extract()` 하나의 결과를 쓴다. 모든 방에서 `ValidExits()`와 화면 링크가 같다는 기존 검사를 유지한다.
- **무작위 도전.** 고정 시드에서 최단 이동 10회 이상인 도전을 고르는 조건을 유지한다.
- **합성 테스트.** 활용형(`같고`·`같으며`·`비슷한데`·`같이`), 관계 명사(수식어 한 어절 건너뛰기), 같은 명사 반복과 `아울러`, 문장부호와 `따위`, 분야 일치, 용례 빈도, 단서가 없을 때 일반 글자, 받침(`교과의`·`효과의`·`사과 같은`), `사과 주스`, `정신과 진료`를 확인한다.
- **기존 기대값 변경.** 문맥 없는 `말과 포유류`가 `[말과] [포유류]`에서 `말과 [포유류]`로 바뀐다. 단서도 분야도 없는 `X과`는 일반 글자가 되기 때문이다. 뜻풀이별 예외를 삭제한 뒤 `[말과]의 포유류`를 검사하는 테스트에는 분야(동물) 문맥을 넣는다.
- `ExceptionProblems()`는 계속 비어 있어야 한다. 일반 규칙과 같은 결과를 내는 예외를 보고하는 검사를 추가하고, 4단계 이후 0건을 유지한다.
- 그래프 생성 시간의 증가를 로그로 측정해 기록한다.
