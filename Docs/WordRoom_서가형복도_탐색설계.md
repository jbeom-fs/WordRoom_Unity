# WordRoom 서가형 복도 탐색 설계

**2026-11-23 · 독립 시안 구현**

WordRoom은 단어의 설명을 읽고 본문 속 링크를 따라 목표 단어의 방에 도달하는 1인칭 탐색 게임이다. 플레이어는 문장을 읽고 다음 단어를 고른다. 같은 도전에서 더 빠른 길이나 이동이 적은 길을 찾는 것이 핵심이다.

`Assets/WordRoom/Scenes/ShelfCorridorPrototype.unity`를 열어 시작한다. 현재 저장된 설정은 `지구`의 행성 뜻에서 `면적`까지다. Inspector에 고정 예제 5개가 있으며, 시안은 메인 메뉴와 빌드 목록에 연결하기 전이다.

## 벽면·단어 문·갈림길

- 방은 표제어와 `SenseId`로 구분한다. 방 하나에는 선택된 사전 뜻풀이 하나를 사용한다. 같은 방에 다시 들어가면 뜻풀이와 문·글의 상대 위치가 같다.
- 일반 글은 별도 배경판 없이 벽 표면에 표시한다. 문짝에는 링크 표제어 하나를 적고 그 아래에 손잡이를 둔다. 글과 문을 읽는 순서대로 이어 붙이면 표시용 뜻풀이가 된다. `항구`의 예는 `염전에서 판에 댈 [바닷물]을 받는 웅덩이.`다. `판`은 한 글자이므로 벽 글로 남는다.
- 왼쪽 벽은 입구에서 안쪽으로 읽는다. 다 들어가지 않으면 남은 부분을 오른쪽 벽의 안쪽부터 입구 방향으로 이어 쓴다. 글자와 문 폭, 문 수납 공간을 기준으로 양쪽 길이를 계산해 필요한 경우 복도를 늘린다.
- E로 손잡이를 당기면 목적지 방과 바닥을 먼저 만들고 문짝을 같은 벽의 수납 공간으로 민다. 서로 다른 `EntryId`가 여럿 남으면 문 뒤 홀에 갈래를 배치하고 각 갈래 위에 짧은 뜻풀이를 표시한다.
- 손잡이 조작과 갈림길 홀 이동은 현재 방·이동 횟수를 바꾸지 않는다. 실제 방 경계를 넘으면 이동 1회를 기록하고 이전 방과 사용하지 않은 갈래를 정리한다.

## 사전과 링크 규칙

- 현재 작업 폴더의 표준국어대사전 패키지는 명사 표제어 15,000개와 뜻풀이 48,318개로 구성된다. 링크는 빈도 상위 15,000개 중 두 글자 이상이며 제한어가 아니고 뜻풀이가 있는 표제어에서 고른다. 길이 조건만 통과하는 표제어는 14,393개다.
- 한자가 든 소괄호는 표시용 뜻풀이를 만들 때 괄호째 지운다. 어절 경계를 지키고, 등록된 어절 전체 또는 허용된 조사·서술 표현 앞의 표제어만 후보로 삼는다. 조사와 문장부호는 벽에 남긴다. 형태가 같은 분리는 실제 문맥을 확인한 어절별·출발 뜻별 예외로 관리한다.
- 자기 표제어는 문으로 만들지 않는다. 같은 유효 표제어가 반복되면 첫 위치에만 문을 만들고 나머지 표기는 벽 글로 둔다.
- `ShelfLinkGraph`는 출구 없는 중간 방을 연쇄적으로 제외한다. 사전 항목마다 남은 뜻 중 하나를 목적지로 고른다. 목표 표제어의 방은 출구가 없어도 목적지로 남는다. 고정 예제에서 출구가 없는 시작 방을 지정하면 방 생성 전에 중단한다.

## 완주·기록·메뉴

- 목표는 표제어 기준이다. `바다 → 지구`에서는 행성 뜻과 땅의 구획 뜻 어느 갈래에 들어가도 완주하고 같은 기록에 반영된다. 시작·목표·현재·HUD 경로와 성공 안내에는 단어 옆 뜻 번호를 표시하지 않는다. 시작 오류와 진단 로그에서는 방을 식별할 수 있도록 번호를 사용한다.
- 첫 조작 가능 시점부터 목표 방 입장까지 시간을 잰다. 사전 로딩·그래프 계산과 첫 조작 전 메뉴 대기는 제외한다. 계측을 시작한 뒤에는 Esc 메뉴에 머무른 시간도 포함한다. 입력 복구 프레임의 실행 순서 문제는 [KI-016](02_Known_Issues.md#ki-016-서가형-타이머가-입력-복구보다-한-프레임-늦게-시작할-수-있음)에 남겼다.
- 결과에는 소요 시간·이동 횟수·개인 최단 시간·최소 이동·`다시 도전`이 있다. 시간은 소수점 둘째 자리까지 표시한다. 경로는 플레이 HUD와 콘솔에서 확인한다.
- 개인 기록은 PlayerPrefs에 저장한다. 키에는 출발 표제어와 `SenseId`, 목표 표제어를 사용한다. 예를 들어 `바다(331764)>지구(*)`는 어느 지구 갈래로 완주하든 공유한다. `다시 도전`은 같은 시작·목표와 방 배치로 이동 0회부터 다시 시작한다.
- Esc 메뉴에는 `재시작`, `설정`, `메인으로`, `게임종료`를 표시한다. `재시작`은 진행 중인 탐색 재개이며 `게임종료`가 동작한다. `설정`·`메인으로`는 메인 메뉴 연결 단계에서 구현한다.

## 다음 작업

1. 고정 도전 선택 UI를 만들고 경로에 따라 이동 횟수가 달라지는 예제를 준비한다. `해안 → 바다 → 면적`과 `해안 → 육지 → 바다 → 면적`처럼 같은 목표의 경로를 비교한다.
2. 서가형 시안을 메인 메뉴에서 시작할 수 있게 하고 Esc 메뉴의 나머지 항목을 연결한다.
3. 무작위 도전을 구현할 때 시작 방에 유효한 문이 없으면 같은 목표를 두고 출발 단어를 다시 고른다. 도전 선택 시에는 목표에 도달할 수 있는 조합을 확인한다.

문 뒤의 뜻을 미리 보는 힌트는 후속 후보이며, 글자 이벤트와 단어·글자를 활용한 전투는 별도 설계 과제다. 육각형 벌집 배치는 폐기했다.
