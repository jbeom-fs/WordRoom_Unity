# WordRoom 단어 링크 판정 설계

**기준일 2026년 11월 26일**

팔각형 독서실에서는 뜻풀이의 단어를 클릭해 해당 표제어의 방으로 이동한다. `ShelfLinkText.FindCandidates()`가 표제어의 시작 위치와 클릭 범위를 정하고, `ShelfLinkGraph`가 같은 추출 결과를 읽기 화면의 링크와 방의 연결에 사용한다. [링크 추출](../Assets/WordRoom/Scripts/Shelf/ShelfLinkText.cs) · [방 그래프](../Assets/WordRoom/Scripts/Shelf/ShelfLinkGraph.cs)

## 와/과 충돌 판정

1. 검수한 뜻풀이별 예외, 동사 활용형 제외, 수량 뒤 단위, 어절별 예외를 적용한다.
2. 어절 전체가 등재되었거나 `의·는·도` 앞에 긴 등재 표제어가 있을 때 `명사 + 와/과` 해석도 검사한다. 짧은 명사의 마지막 음절에 받침이 있으면 `과`, 없으면 `와`를 후보에 넣는다. `사과 같은`은 `[사과]`를 유지한다.
3. 가까운 어절에서 비교·동반·상호 표현, 관계 명사, 같은 명사의 반복, `아울러·통틀어`에 따른 나열을 확인한다. 앞으로 문맥을 볼 때 문장부호와 줄바꿈에서 멈춘다. 나열 앞에 이미 `명사 + 와/과`가 있으면 `계열과 공과 계열을 아울러`처럼 뒤의 긴 표제어가 두 번째 항목을 수식할 수 있다.
4. 뒤 명사에 목적격 또는 수단 조사가 붙은 경우에는 사전의 다른 뜻풀이에 확인된 병렬 용례도 확인한다. `A(이)나 B`와 `A적·B적` 구문에서 두 등재 명사가 연결된 용례를 사용한다. 이 용례와 현재 문장의 조사 표지가 함께 있을 때 조사 해석을 고른다.
5. 문맥 근거가 부족하면 기존의 전체 표제어 우선과 유일한 분리 후보 규칙을 적용한다. 선택한 표제어에 길이, 순위, 제한어, 뜻풀이 조건을 적용한다. 선택한 표제어가 조건을 통과하지 못하면 그 자리에는 링크를 만들지 않는다.

방 그래프와 읽기 화면은 같은 뜻풀이별 추출 결과에 씬의 링크 설정, 자기 방 제외, 첫 번째 위치 우선, 목적지 유효성 조건을 적용한다. [링크 필터와 그래프](../Assets/WordRoom/Scripts/Shelf/ShelfLinkGraph.cs)

## 대표 뜻풀이

| 출처 | 변경 전 → 변경 후 | 판정 근거 |
|---|---|---|
| 기린·인수·유니콘 | `[말과] 같으며` / `[말과] 같고` → `말과 같으며` / `말과 같고` | 비교 표현의 활용형 |
| 당나귀 | `[말과]의 포유류` 유지. `말과 비슷한데`의 후보는 추출에서 제거 | 첫째는 검수한 분류명, 둘째는 비교 표현 |
| 조사·토 | `그 말과 다른 말과의 문법적 관계`의 두 위치 모두 일반 글자 | `다른`, `문법적 관계` |
| 하천 | `[강과] [시내]를 아울러` → `강과 [시내]를 아울러` | 목적격과 `아울러` |
| 연극 | `[말과] [동작]으로` → `말과 [동작]으로` | 수단 조사와 외상의 `말이나 동작` |
| 문장 | `[말과] [글로] 표현할` → `말과 [글로] 표현할` | 수단 조사와 소식의 `말이나 글` |
| 수행 | `[정신과] [육체]를 훈련` → `[정신]과 [육체]를 훈련` | 목적격과 노력의 `정신적·육체적인`. 뒤쪽 `[정신]의 정화`는 같은 뜻풀이의 첫 위치 우선에 따라 일반 글자로 바뀜 |
| 프로이트 | `[신경과] [의사]` 유지 | 조사 해석을 뒷받침하는 단서가 없는 명사구 |
| 숙제 | `[방과] [후에]` 유지 | 시간 표현 |
| 본회의 | `[분과] 회의에` 유지 | 회의 유형 |
| 파스칼·케임브리지 | `[공과] [대학]에서` / `[공과] 대학 따위` 유지 | 대학의 학과 계열 |
| 이공계 | `[이과] [계열]과 [공과] 계열을 아울러` 유지 | `공과`가 나열의 두 번째 항목인 `계열`을 수식 |
| 복수 | `[경과] 중에도` 유지 | 질환의 경과 |
| 메커니즘 | `[인과] [관계]와` 유지 | 원인과 결과의 관계 |

`산정`의 `[산과] 들`, `갈매기`의 `[등과] 날개는`, `공안`의 `[말과] 행동`은 현재 규칙으로 확정할 문맥 단서가 부족해 남는다. `참모`의 `윗사람을 [도와]`는 `돕다`의 활용과 명사 표제어의 충돌이다. `[글로]`, `[귀가]`, `[말의]`는 각각 다른 조사 경계에서 생기는 오류다. [사전 원문](../Assets/StreamingAssets/WordRoomData/senses.json)

화면의 `[말과]`는 21건에서 7건으로 줄었다. 남은 7건 중 당나귀의 분류명은 정상 링크다. 천이·대인·어학연수·장차·공안·내시의 나열에는 현재 규칙이 요구하는 명시적 구문이나 조사와 병렬 용례가 함께 나타나지 않는다.

## 검증

Unity EditMode에서 패키지 `6773adfc0093…`의 15,000개 표제어와 48,318개 뜻풀이를 읽고, `ShelfCorridorPrototype` 씬의 상위 15,000개·최소 2글자·뜻풀이별 링크 선택을 적용했다. 스냅샷은 뜻풀이별 원문과 표시용 본문, 추출 후보와 실제 표시 범위의 위치·길이·클릭 글자·목적지를 담는다. [회귀 검사](../Assets/WordRoom/Tests/EditMode/ShelfLinkTextTests.cs)

목표 `면적`, `지구`, `우정`에서 표시 링크의 변경 내역이 같았다. 오링크 91건을 제거하고 정정 5건을 적용했다. 선인·신선은 `자연과 → 자연`, 수행·신기·신혼은 `정신과 → 정신`으로 바뀌었다. 수행의 기존 정상 클릭 위치 1곳은 앞쪽으로 옮겨졌고 정상 목적지 소실과 새 오링크는 각각 0건이다. 당나귀의 두 번째 `말과`는 중복 제거 전의 추출 결과에서도 사라졌다.

본문 복원과 자기 방·중복 링크 제외, 읽기 화면 데이터와 그래프 출구의 일치를 확인했다. 난수 시드 `20261126`의 도전은 `위풍당당 → 우정`이며, 읽기 화면의 링크로 별도로 계산한 최단 거리는 10회다. Unity EditMode에서 기존·회귀 검사 97개와 전수 비교 검사 1개가 통과했고, 기존 검사 1개는 건너뛰었다. PlayMode의 실제 클릭 조작은 미확인이다.
